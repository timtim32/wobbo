Wobbo {{VERSION}}: small Wobbos on your desktop that show what your Claude Code sessions are doing.

## Install

1. Download **Wobbo.dmg** below and open it.
2. Drag **Wobbo** onto the **Applications** folder.
3. Open Wobbo from Applications.

### The first time you open it

Wobbo is not notarized by Apple yet, so macOS stops it the first time:

1. macOS says Wobbo "Not Opened". Click **Done**.
2. Open **System Settings → Privacy & Security** and scroll down.
3. Next to "Wobbo was blocked to protect your Mac", click **Open Anyway**, then confirm.

After that, Wobbo opens like any other app.

## Connect to Claude Code

When Wobbo starts for the first time, Wobbo walks in and asks to connect to Claude Code. Click **Connect to Claude Code**. New Claude Code sessions then each get their own Wobbo. Restart sessions that were already open.

You can connect or disconnect later from Wobbo's menu bar icon.

## Good to know

- **Dock:** to step aside for an auto-hidden Dock, Wobbo asks for Accessibility access. Allow it in System Settings → Privacy & Security → Accessibility.
- **Start at login:** turn on **Open at Login** in Wobbo's menu.
- **Updating:** download the new Wobbo.dmg and drag Wobbo to Applications again. Wobbo updates its Claude Code connection by itself.
- **Requirements:** macOS 13 or later, on Apple silicon or Intel, and Claude Code.
